Backup dos Dados

Este sistema é 100% local/offline: os dados ficam salvos apenas neste computador, dentro deste navegador (não há nuvem, não há internet envolvida). Por isso é essencial exportar um backup (.json) regularmente e guardá-lo em local seguro (pendrive, outro HD, etc.) — se o navegador limpar os dados ou o computador tiver problema, um backup recente é a única forma de recuperar as informações.

Importar um backup substitui todos os dados atuais pelos dados do arquivo.

🧮 Calculadora Financeira

M+ / M- somam ou subtraem da memória, MR mostra e MC limpa. Também funciona digitando no teclado do computador (Enter = igual, Esc fecha).

Digite números normalmente ou uma fórmula começando com "=", ex.: =A1+B2 ou =SOMA(A1:A5) (aceita SOMA ou SUM). A última coluna soma cada linha e a última linha soma cada coluna.
